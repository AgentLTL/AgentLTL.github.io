# Formulas

Formulas are immutable dataclasses; combine them freely, and wrap one in a
[`Constraint`][agentltl._constraints.Constraint] to check it. All of them are importable from
`agentltl`. The [formula table](../index.md#foltl-formula-reference) gives a one-line summary
of each.

## Building from a string

::: agentltl._parser.parse
    options:
      show_root_heading: true
      heading_level: 3

## Formula nodes

::: agentltl._ast
    options:
      heading_level: 3
