# Traces and verification

A [`Trace`][agentltl._trace.Trace] is the ordered list of tool calls; a
[`Constraint`][agentltl._constraints.Constraint] names and weights a formula;
[`verify_trace`][agentltl._constraints.verify_trace] checks constraints on a finished run and
computes the compliance score.
